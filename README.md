🚀 تشغيل التطبيق

يمكن تشغيل النسخة الأساسية مباشرة بفتح:

KMA_Pro_3.0.html

ولا يحتاج الإصدار الأساسي إلى قاعدة بيانات لتخزين المهام والملاحظات والإعدادات، لأنها تُحفظ محليًا باستخدام "LocalStorage".

🤖 ربط المساعد الذكي

واجهة المساعد موجودة داخل التطبيق، ويمكن ربطها بخادم Backend.

في ملف HTML:

const AI_BACKEND_URL="";

ضع رابط الـBackend:

const AI_BACKEND_URL="https://YOUR-BACKEND-DOMAIN/api/chat";

⚠️ مهم جدًا: لا تضع مفتاح API السري داخل ملف HTML أو داخل GitHub.

يجب أن يبقى مفتاح API داخل متغيرات البيئة في الـBackend.

🌐 GitHub Pages

يمكن نشر واجهة KMA Pro 3.0 باستخدام GitHub Pages.

KMA_Pro_3.0.html

index.html
